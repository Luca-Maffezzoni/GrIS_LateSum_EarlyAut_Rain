#=================================================================================NOTE==============================================================
The multy_year_velocity_flow of each flow lines was is calculated applying on QGIS software the script "03_qgis_buffer_mean_velocity_along_single_flowline.py"
This script was made with QGIS software version 3.10.1 not directly writing but with the MODEL BUILDER tool.
This script must be run within QGIS (Processing Toolbox → run script)

As input you must in insert manually the flow line of interest from the Folders: 1) Data/INPUT/GIS_SITE_A/SITE_A_flow_lines_shape or Data/INPUT/GIS_SITE_B/SITE_B_flow_lines_shape and 
than the raster "greenland_vel_mosaic250_vv_v1.tif" located in "Data/RAW" folder which represent the Multi-year Greenland Ice Sheet Velocity Mosaic. (NSIDC-0670, Version 1)
