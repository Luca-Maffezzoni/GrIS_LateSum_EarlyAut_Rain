In this folder, parameters have been extracted year by year without applying any mask.

The extracted files related to the SMB and RU variables are used by the scripts "extract_sum_ruonff_1985_2015.py" 
and "SMB_1985_2015.py", located in Code/met_glacio_parameters_extraction, to compute the corresponding .nc output files 
stored in Data/PROCESSED/MET_GLACIO_PARAMETERS.

The extracted files related to the TTZ, CM, and RF variables are required as input for the scripts located 
in Code/meteorological_analysis, respectively for Site A and Site B.
